# 🌍 ClimateHero — Узнай о глобальном потеплении и помоги планете!

## Что это за сайт?

ClimateHero — это сайт где школьники и все желающие могут узнать про глобальное потепление и получить список действий подобранных именно под их возраст.

---

## Как запустить?

### Шаг 1 — Установи библиотеки

Открой терминал и напиши:

```
pip install flask flask-login flask-sqlalchemy werkzeug
```

### Шаг 2 — Запусти сайт

```
python app.py
```

### Шаг 3 — Открой браузер

```
http://localhost:5000
```

---

## Структура файлов

```
climatehero/
├── app.py              главный файл, запускай его
├── README.md           этот файл
├── templates/
│   ├── base.html       шапка и футер
│   ├── index.html      главная страница
│   ├── register.html   регистрация
│   ├── login.html      вход
│   └── dashboard.html  советы по возрасту
└── climate.db          база данных (создаётся сама)
```

---

## Как это работает?

- Ты регистрируешься и вводишь дату рождения
- Все данные сохраняются в базу данных
- Пароль хранится зашифрованным — никто его не увидит
- После входа сайт считает твой возраст и выдаёт советы

---

## Советы по возрасту

| Возраст | Группа |
|---------|--------|
| до 10 лет | простые домашние привычки |
| 11–14 лет | школа и дом |
| 15–17 лет | активизм и осознанные выборы |
| 18–25 лет | студенческие и гражданские действия |
| 26–60 лет | работа и семья |
| 60+ лет | передача опыта |
